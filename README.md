# White Noise

Randomly play sound for sleeping and focusing

## What is this
* Randomly plays sound from your collection of audio files
* Starts with fading in to not disturb
* Finishes playing in 1.5h
  * cf. It's recommended white noise is played less than 8h per day

## Prerequisites
* Place mp3 files under `music` directory
* `pnpm start`

## Controlling options
* On command line, Hit space bar to start and stop
* Access http://0.0.0.0:3456 to see web UI
* There are /on, /off and /change API under http://0.0.0.0:3456

## Tips

* Download mp3 from YouTube https://savemp3.net/xksom
  * Clip to less than 2 hours
